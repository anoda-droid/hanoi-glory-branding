## Cấu trúc

- `branding/brand-guide.md`: định hướng thương hiệu, màu sắc, typography, tone of voice.
- `assets/logo/hanoi-glory-logo.svg`: logo SVG có thể dùng ngay.
- `assets/images/`: ảnh minh họa AI để dùng tạm khi chưa chụp ảnh thật.
- `site/`: landing page tĩnh cho hanoiglory.com.

## Chạy thử website

Mở trực tiếp `site/index.html` hoặc chạy:

```bash
cd site
python3 -m http.server 8080
```

Sau đó truy cập `http://localhost:8080`.
